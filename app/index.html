AWS DevOps Practical Assessment

Application status: HEALTHY

This demo application is deployed on Amazon EC2 using a Launch Template and Auto Scaling Group behind an Application Load Balancer.

Infrastructure

  • Amazon VPC across two Availability Zones
  • Public ALB and private EC2 instances
  • Private encrypted Amazon RDS for MySQL
  • AWS Secrets Manager and Amazon S3
  • Terraform Infrastructure as Code
  • GitHub Actions CI/CD with OIDC
Assessment demo — do not use as a production application without further hardening.
